# Word Adventure — Complete Version

Tablet-friendly Grade 3–7 learning PWA with:
- Full-screen category screens with back arrows
- 800 English spelling words
- English and Afrikaans vocabulary and spelling
- Read-aloud for lessons, stories, questions and answer options
- 100 original stories: 50 English + 50 Afrikaans
- Story comprehension practice
- Word games, memory, missing-letter, unscramble, sentence builder, translation and speed challenge
- Maths practice: operations, tables, fractions, money, measurement, geometry, patterns and word problems
- Time learning
- Personal dictionary and progress tracking
- Stars, levels, badges and encouraging feedback
- No lives
- PWA install support and offline caching

## GitHub Pages
Upload all files in this folder to the root of the `learn` repository. Ensure `index.html` is at the repository root. Then use GitHub Pages from the `main` branch/root.

Educational design was informed by public guidance emphasizing structured literacy/numeracy practice, reading at levels, comprehension, spelling, vocabulary, games and interactive feedback. Content in this app is original and is not copied from third-party workbooks or websites.
